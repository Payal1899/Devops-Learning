How to connect:
1. Open an SSH client
2. Locate or download your private key file(.pem file) in git we have already added that
3. Ensure your key is not publicly viewable(setting write permissions)
run below in local machine(codespace)
chmod 400 "Course.pem"
4. Connect to your instance using its Public DNS(run below from codespace)(-i for identity)
ssh -i "Course.pem" ubuntu@ec2-3-90-218-5.compute-1.amazonaws.com
now as the codespace ip address is changing with each session we need to modify ip in inbound rule every time we are connecting ec2 instance.
